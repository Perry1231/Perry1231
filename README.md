## 🚀 About Me

I'm a passionate **Electronics & Embedded Systems Engineering** student at **Lviv Polytechnic National University (ICTA, Specialty 171 / G5)**, actively engaged in the **Erasmus+ exchange program**. 

I specialize in **low-level C++ programming**, microcontroller firmware development (**ESP32 / ESP8266**), multi-sensor hardware integration, and building full-stack hardware/software solutions.

- 🎓 **Education**: Lviv Polytechnic National University (Institute of Computer Technologies, Automation and Metrology)
- 🌍 **International Experience**: Erasmus+ Exchange Program
- ⚡ **Current Focus**: Multi-sensor motion tracking wearable hardware, custom PCB/circuit assembly, and high-performance C++ algorithmic problem solving.
- 🌐 **Web & API Projects**: Designing scalable backend infrastructure and AI API services.
- 🧩 **Hobbies**: Algorithmic challenges (LeetCode), hardware prototyping, circuit soldering, gaming mechanics & physical fitness.
